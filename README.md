# TypeSpeak — ระบบฝึกพิมพ์ดีดและฝึกอ่านออกเสียง 2 ภาษา (TTS)

เว็บแอปพลิเคชันฝึกพิมพ์สัมผัสควบคู่กับการฝึกฟังและออกเสียงภาษาอังกฤษ (`en-US`) และภาษาไทย (`th-TH`) ด้วยเทคโนโลยี Web Speech API (Text-to-Speech) ออกแบบสีสันและระบบ Gamification ให้เหมาะสำหรับนักเรียนและผู้เรียนทุกวัย

## ฟีเจอร์หลัก

- **รองรับ 2 ภาษา**: สลับภาษาไทย (`th-TH`) และภาษาอังกฤษ (`en-US`) ได้ทันที
- **3 โหมดการฝึก**:
  - **โหมดเวลา (Time Mode)**: `15s`, `30s`, `60s`, `120s` หรือกำหนดเวลาเอง (`5 - 600` วินาที)
  - **โหมดจำนวนคำ (Words Mode)**: `10`, `25`, `50`, `100` คำ หรือกำหนดจำนวนคำเอง (`1 - 500` คำ)
  - **โหมดประโยค (Sentence Mode)**: ฝึกพิมพ์และฟังเสียงอ่านทั้งประโยค
- **ระบบอ่านออกเสียง (TTS)**:
  - อ่านคำศัพท์อัตโนมัติขณะพิมพ์ หรืออ่านทั้งประโยคในโหมดประโยค
  - คลิกที่คำใดก็ได้บนหน้าจอเพื่อฟังเสียงอ่านซ้ำทีละคำ
  - เลือกโมเดลเสียง ปรับความเร็ว (`0.25x - 2.00x`), ระดับโทนเสียง (Pitch) และความดัง (Volume)
- **ธีมสีสันสดใส 5 สไตล์**: นีออนป๊อป, พาสเทลแคนดี้, มิ้นต์โซดา, ซันเซ็ตพีช และคลาสสิก
- **ระบบสถิติและ Gamification**: คำนวณ WPM, Raw WPM, Accuracy, Consistency, Combo Streak และบันทึกสถิติสูงสุดลง `localStorage`

## Tech Stack

- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **TTS**: Web Speech API (`window.speechSynthesis`)
- **Icons**: Lucide React

## วิธีติดตั้งและรันโปรเจกต์

1. ติดตั้งแพ็กเกจ:
   ```bash
   npm install
   # หรือบน Windows PowerShell:
   npm.cmd install
   ```

2. รันเซิร์ฟเวอร์สำหรับพัฒนา:
   ```bash
   npm run dev
   # หรือบน Windows PowerShell:
   npm.cmd run dev
   ```

3. เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

## เผยแพร่ให้นักเรียนใช้งาน

`localhost` ใช้ได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์เท่านั้น หากต้องการลิงก์สาธารณะ สามารถใช้ Vercel Hobby ซึ่งมีค่าใช้จ่าย $0/เดือนและให้ URL `vercel.app` โดยไม่ต้องซื้อโดเมน:

1. ส่งโปรเจกต์เวอร์ชันที่ต้องการเผยแพร่ขึ้น GitHub
2. ล็อกอิน Vercel แล้วเลือก **Add New → Project** จากนั้น Import repository นี้
3. ตรวจสอบให้ Framework Preset เป็น **Next.js** และใช้คำสั่ง Build `npm run build` แล้วเลือก **Deploy**
4. เลือกแผน Hobby (ฟรี) และ Deploy เมื่อสำเร็จจะได้ URL เช่น `https://ชื่อโปรเจกต์.vercel.app` ใช้ URL นี้ส่งให้นักเรียน หรือใช้เป็น `src` สำหรับฝังในเว็บ

แผนฟรีมีโควตาการใช้งาน และข้อกำหนดของ Vercel Hobby ระบุไว้สำหรับการใช้งานส่วนบุคคลที่ไม่ใช่เชิงพาณิชย์ ควรตรวจสอบข้อกำหนดปัจจุบันให้เหมาะกับรูปแบบการใช้งานของโรงเรียนก่อนเผยแพร่

ตัวอย่างโค้ดฝังแอปในหน้าเว็บ (แทน URL ตัวอย่างด้วย URL ที่ได้จาก Vercel):

```html
<iframe
  src="https://ชื่อโปรเจกต์.vercel.app"
  title="ระบบฝึกพิมพ์ TypeSpeak"
  width="100%"
  height="850"
  style="border: 0"
  loading="lazy"
></iframe>
```

หากแก้โค้ดไว้ในเครื่องแต่ยังไม่ได้ส่งขึ้น GitHub ให้ commit และ push เวอร์ชันนั้นก่อน Deploy เพื่อให้ลิงก์สาธารณะมีการแก้ไขล่าสุดด้วย
